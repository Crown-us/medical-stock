# RakObat

Halaman penawaran RakObat, sistem stok untuk apotek: obat masuk dan keluar per nomor batch, FEFO, peringatan ED, stok minimum, stock opname, dan laporan.

Situs statis satu halaman (`index.html` + `img/`), tanpa proses build. Buka `index.html` langsung di browser, atau lihat lewat GitHub Pages.
